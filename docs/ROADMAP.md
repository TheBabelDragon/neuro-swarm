# Roadmap (post this branch)

1. Select LoRa module + document regional config + implement one adapter
2. Wire IMU + battery ADC on Flying Breadboard revision A
3. ESP-IDF project files for airborne and ground targets
4. SoftAP + embedded static file serving + WebSocket push
5. Field RSSI mapping and packet-loss characterization
6. Optional: bidirectional low-rate command channel with explicit safety interlocks
7. Optional: dual-domain swarm analytics consuming both sim and physical streams

Neural → motor mapping remains out of scope until a dedicated safety design exists.
